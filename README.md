**Stack** &nbsp; `React` `FastAPI` `Django` `SQLite` `ERDCloud` `Figma`

- **위기 극복**: 팀원 중도 이탈 후 2인 체제로 역할을 재조정해 기획된 전 기능, DB 연동, 배포까지 완수
