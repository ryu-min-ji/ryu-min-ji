# 📂 Projects

## 🎵 똑똑(TokTok) - 시니어 AI 생애여정 음악 지도 서비스 (진행중)

> 주야간보호센터 어르신의 생애 인터뷰를 AI 맞춤형 노래로 제작하고, 회기 일지와 대형 자막 노래방 기능을 제공하는 시니어 케어 서비스

### 담당 역할 & 기여
- **Frontend Lead** : UI/UX 설계 및 화면 전체 구현
- 시니어 사용성 및 시설 종사자 환경을 고려한 직관적인 대형 자막 노래방 모드 구현
- AI 생성 가사/음원 실시간 렌더링 및 일지 자동 생성 결과 상태 관리

### Tech Stack
- Frontend : React · TypeScript · Vite
- Styling : Tailwind CSS
- Tools : Figma · GitHub

## 🏛 ACT:ON - 국민 참여형 법안 피드백 대시보드

> 국회 Open API를 활용해 실시간 법안 정보를 시각화하고, 시민 의견 수렴 및 찬반 투표를 지원하는 웹 플랫폼

### 주요 기능 & 역할
- 국회 Open API 기반 법안 목록 조회, 카테고리/상태별 실시간 필터링 UI 구현
- 법안별 찬반 투표 컴포넌트 및 댓글/토론방 기능 연동
- 마이페이지 참여 이력 대시보드 개발

### Tech Stack
- Frontend : React
- Backend : FastAPI
- Database : MySQL
- Tools : Figma · GitHub · ERD Cloud

🔗 [GitHub Repository](https://github.com/ryu-min-ji/MGP)

## ⚽ We Play - 스포츠 커뮤니티 웹 서비스

> KBO 경기 일정 조회, 실시간 응원 채팅, 게시글 및 멀티미디어 공유를 지원하는 올인원 스포츠 팬 플랫폼

### 주요 기능 & 역할
- Socket.io 연동을 통한 실시간 경기 응원 채팅방 구축
- TheSportsDB API 연동 기반 실시간 경기 일정 및 결과 화면 렌더링
- 게시글/댓글 CRUD, Multer 기반 이미지 업로드 및 Cloudflare Pages / Render 배포

### Tech Stack
- Frontend : HTML5 · CSS3 · JavaScript (ES6+)
- Backend : Node.js · Express
- Database : Railway MySQL
- Real-time : Socket.io
- Deploy : Cloudflare Pages · Render

🔗 [GitHub Repository](https://github.com/ryu-min-ji/sport-community)
